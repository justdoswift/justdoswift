# Small interactions, considered individually

Format: six independent 1080 × 1080, 30 fps, 8-second silent H.264 videos.
Shared frame: warm neutral canvas, restrained editorial title, centered interface, instructional footer. No externally sourced media, fonts, music, or tracking.

| Composition | Character | Timing |
| --- | --- | --- |
| PhotoStack | Tactile travel postcards, sage / blue / terracotta | 0–1.1s stack; 1.1–2.2s unfold; 2.2–4.1s hold; 4.1–5.2s gather; 5.7–7.2s swipe |
| HoldToConfirm | Intentional, reassuring, sage green | 1–1.8s cancelled hold; 3.2–4.7s complete hold; 4.7–6.7s success; then reset |
| MiniPlayer | Warm geometric artwork, continuous expansion | 1.2–2.1s expand; 3.3s play; 5.7–6.8s collapse; 7.3s pause |
| ReactionPicker | Friendly social card, original neutral layout | 1.4s hold; 1.9s tray; 2.4–4.3s hover selection; 4.5s commit |
| SendButton | Clear asynchronous feedback, slate / green | 0.3–1.6s type; 2.3s sending; 3.9–6.4s sent; reset |
| PullToSearch | Quiet bookmark collection, olive accents | 0.8–1.6s pull; 1.6–2.3s reveal; 3–3.9s type/filter; 6s cancel |

Final 18 frames dissolve back to the exact first frame for looping.
Touch rings illustrate the user's gesture, not a live cursor or native screen capture.
Native implementations and video demonstrations are separate implementations, explicitly labeled.
